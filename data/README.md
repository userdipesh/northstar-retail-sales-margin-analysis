# Dataset

This project uses Tableau's Sample Superstore dataset, a fictional retail dataset commonly used for analytics and data visualisation practice.

For this portfolio project, I created the fictional **NorthStar Retail** business scenario around the dataset.

The dataset includes information such as:

- Orders
- Products and categories
- Customer segments
- Regions
- Sales
- Quantity
- Discounts
- Profit

## Dataset Summary

- **10,194 transaction-line records**
- **5,111 unique orders**
- **Analysis period:** January 2023 to December 2026

## Source

Original dataset: **Tableau Sample Superstore / Tableau Public Sample Data**

The value of this portfolio project is in the SQL analysis, Power BI reporting, business interpretation, and recommendations developed from the sample data.
